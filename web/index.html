Set up your button

Your button comes ready to go. Use this page to set it up from a computer, reinstall the firmware, or update it.

Set up from a computer (easiest)

  1. Plug the button into your computer with a USB-C data cable. Some charge-only cables won't work.
  2. Click Connect below and pick the port that appears. It's usually "USB JTAG/serial debug unit".
  3. Enter your 2.4 GHz Wi-Fi network and password when asked.
  4. Click Visit device to open the button's settings page, then fill in your printer server details.

This browser can't talk to USB devices. Use Chrome or Edge on a Windows, Mac, or Linux computer, or use the phone setup below.

This page has to be opened over HTTPS to connect.

You'll also see options to reinstall or update the firmware. Reinstalling with "erase" clears all settings.

Set up with a phone and a computer

  1. Power the button from any USB charger. When it isn't set up yet, it glows blue.
  2. On your phone, join the Wi-Fi network named like ClearCue-1A2B.
  3. The setup page should open on its own. If it doesn't, go to http://192.168.4.1.
  4. Pick your Wi-Fi network, enter its password and tap Connect. The phone then shows the button's address, like http://clearcue-1a2b.local.
  5. On a computer on the same Wi-Fi, open that address and fill in your printer server details. The light blinks blue slowly until you do.

No computer? On the phone's setup page, tap "Set up everything on this phone instead".

What the lights mean

  1. Solid green: the printer is ready, nothing to do.
  2. Solid red: the printer is busy, or the plate needs clearing. Press once you've cleared it.
  3. Solid blue: setup mode. The button's own setup Wi-Fi network is on. It also comes on if the button loses your Wi-Fi for more than 5 minutes.
  4. Slow blue blinking: on your Wi-Fi, but the printer server details still need filling in on the settings page.
  5. Fast red/green alternating: connecting to Wi-Fi.
  6. Slow red blinking: can't reach your printer server. Open the settings page and click Test connection.

Troubleshooting

The Connect button doesn't find my button

Try a different USB cable or port. If it still doesn't appear, unplug the button, hold the small BOOT button on the board, plug it back in, then let go and try again.

I forgot the settings password, or want to start over

Hold the big button for 10 seconds. The light flickers white after 3 seconds; keep holding. The button erases its settings and goes back to setup mode.

Where's the settings page after setup?

On the same network, open http://<device-name>.local (shown on the setup page), or the button's IP address from your router.
